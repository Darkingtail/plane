# Reference — Plane CE 参考资料

[TOC]

> 本目录存放对 Plane CE 的客观参考文档，用于回答「CE 原生支持什么？Pro 独占什么？」等问题，是二开决策和升级评估的基础依据。

---

## 文件列表

| 文件                    | 内容                          | 主要用途                               |
| ----------------------- | ----------------------------- | -------------------------------------- |
| `plane-capabilities.md` | CE 全量能力清单（经源码实测） | 判断某功能是否需要二开，还是 CE 已内置 |
| `plane-editions.md`     | CE vs Pro 版本差异对比        | 评估某功能是付费专属还是开源可用       |

---

## 何时查阅

| 场景                                            | 推荐查阅                                 |
| ----------------------------------------------- | ---------------------------------------- |
| 准备开发新功能前，确认 CE 是否已有              | `plane-capabilities.md`                  |
| 遇到「源码里有占位 / 但不生效」的功能           | `plane-editions.md`（确认是否 Pro 专属） |
| 合并上游版本，评估新 feature 是否影响我们的二开 | 两者结合                                 |
| 向团队说明「为什么要自己实现 X」                | `plane-editions.md` 提供论据             |

---

## 维护说明

- 内容基于实测，不依赖官方文档（官方文档可能过时或混淆 CE/Pro）
- 每次合并上游大版本后，检查并更新受影响条目
- 若发现官方已将某功能下放至 CE，在对应条目标注并更新状态
