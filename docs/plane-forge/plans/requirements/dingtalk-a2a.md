# PF-010: 钉钉 → Plane 需求录入 (A2A)

> 创建日期: 2026-03-13

## 背景

当前需求录入依赖人工在 Plane 中手动创建 Issue，存在以下问题：

- 业务人员不熟悉 Plane 操作
- 需求散落在钉钉群聊、文档、会议纪要中，容易遗漏
- 手动录入格式不统一，缺少结构化信息

钉钉已开放 MCP 能力（文档读写、消息、待办等），Plane 也有 MCP Server（55+ 工具）。可以构建 A2A（Agent-to-Agent）场景，让两个 Agent 协作完成需求从描述到工作项的自动化流转。

## 目标

用户在钉钉中用自然语言描述需求，自动创建为 Plane Issue，并双向同步状态。

## 核心流程

### 流程 1: 群聊需求捕获

```
1. 用户在钉钉群中 @AI助手 描述需求
2. 钉钉 Agent 通过 MCP 读取消息上下文
3. 钉钉 Agent 提取结构化信息:
   - 标题、描述、优先级
   - 提出人（钉钉 → Plane 用户映射）
   - 相关文档链接
4. 通过 A2A 协议发送给 Plane Agent
5. Plane Agent 通过 MCP 创建 Intake 工作项
6. Plane Agent 返回工作项链接
7. 钉钉 Agent 在群里回复确认 + 链接
```

### 流程 2: 文档需求批量导入

```
1. 用户在钉钉文档中整理需求列表（会议纪要/PRD）
2. 用户 @AI助手 "把这个文档的需求录入 Plane"
3. 钉钉 Agent 通过 MCP 读取文档全文
4. 钉钉 Agent 解析拆分为多条结构化需求
5. 逐条通过 A2A 发送给 Plane Agent 创建 Issue
6. 汇总创建结果回复用户
```

### 流程 3: 状态变更反向通知

```
1. Plane Issue 状态变更（通过 Webhook 或轮询）
2. Plane Agent 识别需要通知的变更
3. 通过 A2A 协议通知钉钉 Agent
4. 钉钉 Agent 通过 MCP:
   - 给提出人发钉钉消息通知
   - 更新钉钉待办状态
   - （可选）在群里播报进度
```

## 技术方案

### 用户映射

钉钉用户 ↔ Plane 用户的映射关系：

| 方案                | 说明                                | 复杂度            |
| ------------------- | ----------------------------------- | ----------------- |
| 邮箱匹配            | 钉钉邮箱 = Plane 邮箱，自动匹配     | 低                |
| 映射表              | 维护钉钉 userId → Plane userId 映射 | 中                |
| PF-008 组织架构同步 | 统一身份源，自动映射                | 高（依赖 PF-008） |

初期建议用邮箱匹配，后续对接 PF-008。

### A2A 协议选型

| 方案            | 说明                              | 适合场景                  |
| --------------- | --------------------------------- | ------------------------- |
| Google A2A 协议 | 标准化 Agent 互操作协议，JSON-RPC | 标准化、多 Agent 生态     |
| 自定义 HTTP API | 简单 REST 调用                    | 快速验证、两个 Agent 场景 |
| MCP 嵌套        | 一个 Agent 作为另一个的 MCP Tool  | 简单集成、单向调用        |

建议：初期用 **MCP 嵌套**（Plane MCP 作为钉钉 Agent 的 Tool），架构简单；后续演进为 **Google A2A** 支持更复杂的多 Agent 协作。

### 钉钉 MCP 能力（待确认）

基于钉钉开放平台 MCP 广场，预期可用的能力：

| MCP Server | 关键 Tools      | 用途                 |
| ---------- | --------------- | -------------------- |
| 钉钉消息   | 读取/发送群消息 | 需求捕获 + 结果通知  |
| 钉钉文档   | 读取/搜索文档   | PRD/会议纪要需求提取 |
| 钉钉待办   | 创建/更新待办   | 双向同步任务状态     |
| 钉钉通讯录 | 查询用户信息    | 用户映射 + @提及解析 |
| 钉钉日历   | 读取日程        | （可选）排期关联     |

> ⚠️ 具体 Tool 列表需查阅钉钉 MCP 广场实际文档确认

### 需求结构化提取

钉钉 Agent 将自然语言转为结构化 Issue 数据：

```json
{
  "title": "支持批量导入用户",
  "description": "从钉钉文档中提取的详细描述...",
  "priority": "high",
  "labels": ["需求", "用户管理"],
  "reporter_email": "zhangsan@wisedu.com",
  "source": "dingtalk_group",
  "source_url": "dingtalk://dingtalkclient/page/link?url=...",
  "attachments": []
}
```
