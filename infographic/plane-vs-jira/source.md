# Plane vs Jira — 为什么选择 Plane？

## 优势一：自主可控

- Plane: 开源自托管，源码完全可控，现代化技术栈（React + Django），支持深度二开
- Jira: 盗版黑盒，无法升级维护，API 不透明，扩展天花板硬，合规风险高
- 关键点: REST API 全量开放 vs 黑盒 API 随时失效；源码可改 vs 无 Marketplace

## 优势二：图表能力碾压

- Plane 内置: Gantt 甘特图 ✅、燃尽图 Burndown ✅、速度图 ✅、日历视图 ✅、数据分析面板 ✅、看板视图 ✅
- 盗版 Jira: 甘特图 ❌、燃尽图 ❌（需付费插件）、速度图 ❌、日历视图 ❌、数据分析 ❌、看板 ⚠️（自建半途卡住）
- 关键点: Plane 开箱即用 6 种视图，Jira 盗版几乎全缺

## 优势三：AI 能力上下限全面领先

### 下限（开箱即用）

- Plane: MCP Server 55+ 工具，IDE 直接读写任务，AI 辅助任务管理
- Jira: 无 MCP，无 IDE 集成，无 AI 能力

### 上限（深度整合）

- Plane 完整 AI 开发工作流: 需求录入(AI生成) → 需求分析(AI拆解) → 需求实现(AI编码) → 需求验证(AI回写) → 需求测试(AI验收)
- Jira: API 黑盒，AI 工具无法稳定接入，完全不可能实现

## 底部总结

- 合规 ✅ 开源无风险
- 能力 ✅ 可视化全面碾压
- AI ✅ 全链路 AI 开发工作流
- 架构 ✅ 二开友好，长期可控
