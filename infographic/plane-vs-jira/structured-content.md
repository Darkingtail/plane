# Structured Content: Plane vs Jira

## Title

Plane vs Jira — 为什么选择 Plane？

## Learning Objectives

1. Understand Plane's 3 core advantages over pirated Jira
2. See concrete capability comparisons in visualization and AI
3. Conclude that Plane is the right choice for the team

---

## Section 1: 自主可控

### Key Concept

开源自托管 vs 盗版黑盒

### Left Column (Plane ✅)

- 开源自托管，源码完全可控
- 现代化技术栈: React + Django
- REST API 全量开放
- 源码可改，深度二开
- 无合规风险

### Right Column (Jira ❌)

- 盗版黑盒，无法升级维护
- API 不透明，随时失效
- 扩展天花板硬
- 无 Marketplace（盗版）
- 合规风险高（著作权法）

### Visual Element

Lock (Jira) vs Unlock (Plane) icon metaphor

## Section 3: AI 能力上下限全面领先

### Key Concept

AI 集成的下限和上限都高于 Jira

### Sub-section A: 下限（开箱即用）

| 能力            | Plane           | Jira |
| --------------- | --------------- | ---- |
| MCP Server      | ✅ 55+ 工具     | ❌   |
| IDE 集成        | ✅ 直接读写任务 | ❌   |
| AI 辅助任务管理 | ✅              | ❌   |

### Sub-section B: 上限（深度整合）

Plane AI 全链路开发工作流:
需求录入(AI生成) → 需求分析(AI拆解) → 需求实现(AI编码) → 需求验证(AI回写) → 需求测试(AI验收)

Jira: API 黑盒，AI 工具无法稳定接入，完全不可能实现
